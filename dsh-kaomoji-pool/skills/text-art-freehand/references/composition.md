# 自由构图、动作和场景

## 让描述成为空间关系

先把用户的要求转为“主体 + 动作 + 接触点 + 环境”。例如“躲在窗帘后偷看”需要遮住一部分主体的前景、露出的目光和一个能读懂的边界。仅把眼睛符号放在窗帘旁边，可能无法表达“后面”。

用三层决定遮挡：背景先画，主体居中，遮挡物或手最后画。不是所有场景都需要完整房间；一个窗框、一截桌边和一盏小灯就可能足够。

## 姿态

站立时重心落在支撑点上；坐姿让身体底边和地面建立接触；趴着时降低高度、拉长水平轮廓。抱东西时决定两只手的位置；递东西时让手伸向接收方；抬头时让眼睛靠近上轮廓，并给上方留空间。

改变姿态时可以重画对应身体图层。工具没有生物解剖知识，不能靠移动一张正面脸自动得到转身。保持同一角色的几个身份特征，其余细节可以为动作服务。

## 场景

先用大块外形划分画面：地面/天空、墙面/窗口、桌面/身体。近处形状大且清晰；远处小且省略。给用户关心的主体留最高的细节密度。

横向放不下时，先试上下关系或近远关系，而不是直接缩小所有字符。两个角色对视要留出视线空间；角色看向画面一侧时，通常在那侧多留空白。

对建筑或器物，选正面和简单斜视即可。先保持同组平行边的方向一致，再考虑装饰；不要混用多个透视方向破坏结构。

## 分格与连续画

两格或三格共用角色轮廓特征和物件标志。每格表达一个变化：准备、动作、结果。可以纵向排，避免窄窗口中两格横排溢出。

保存每格的自绘图层和位置，编辑时只改当前动作。图层 id 用格名区分。全景中的静物可以复用自己的图层数据，但不把所有主体机械复制到每一格。

## 看不清时如何修

先删除非必要装饰，放大最关键的接触点或轮廓变化；必要时换视角。加标题只能解释画面，不能代替画面的表达。修改一次后再次查看成品，保留有效变化，不在无关细节上无限打磨。
