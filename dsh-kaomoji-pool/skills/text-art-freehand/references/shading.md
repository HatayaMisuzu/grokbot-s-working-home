# 明暗、纹理与体积

稀疏线稿往往比密集填充更适合聊天。只有用户要体积、材质或较完整作品时再使用明暗。

先选单一光源，例如左上。朝光处留白，背光处逐渐增加字符密度。可以从空格、点、冒号到较密的 `+ * # @` 逐级选择，但每种字体的黑度不同，这只是起点。

不要用同一种纹理同时填满主体和背景。毛发可用疏密变化与边缘小断线；金属可用清楚的反光带；水面可用水平短线和断开的倒影；云用圆润外轮廓与稀疏内部线。

在低分辨率文字画中，阴影最有用的三个位置是：主体与地面接触处、一个物体遮住另一个物体的地方、弯曲表面的背光侧。先做好它们，再考虑更复杂的排线。

块状符号与 Braille 更适合密集图案，不能直接按普通 ASCII 单元任意混排。需要时建立统一字符集合，控制密度，并用 unicode 指导核对实际字体。不要声称工具会把照片自动转换成字符图，它没有图片读取或图像采样功能。

椭圆和矩形的 fill 适合试放大块阴影；自然纹理通常用自己绘制的 text 图层更容易控制。给重要轮廓留清晰边界，避免填充把主体淹没。
